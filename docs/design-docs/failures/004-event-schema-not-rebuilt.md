# 004. event-schema 를 고쳐도 이미지가 안 구워졌다

## 증상
`event-schema` 의 스키마나 `KafkaTraceLink` 를 고치고 머지했는데 운영에 반영되지 않았다. CD 는 초록불로 끝났다.

## 원인
CD 의 변경 감지가 바뀐 모듈만 다시 굽는다. 모듈 판별은 디렉터리 이름이 `*-service` 인지로 하는데, **`event-schema` 는 라이브러리라 그 패턴에 안 걸린다.** 공통 파일 목록에도 없었다.

그래서 아무 이미지도 안 구워지고 매니페스트만 다시 apply 됐다. 파드는 옛 이미지 그대로다.

여기에 CD 주석이 "모듈끼리 의존이 없다" 고 적혀 있었다. 사실이 아니었다. 여섯 서비스가 전부 `project(':event-schema')` 를 참조한다.

## 해결
`event-schema/` 를 공통 파일 목록에 넣어 바뀌면 전 모듈을 다시 굽게 했다(#267). 틀린 주석도 고쳤다.

## 재발 방지
- CD 주석에 왜 공통 파일인지와 빼면 무슨 일이 생기는지를 적었다.
- 같은 유형이 한 번 더 있었다. `shared-resources/` 가 빠져 있어 관측 설정을 바꿔도 이미지가 안 구워졌다. 둘 다 "매니페스트만 반영되고 파드는 옛 이미지" 라 조용하다.
