# 결정 기록 (ADR)

설계·구조, 기술·라이브러리 선택, 구현 방식, 버린 대안을 하나씩 적는다. 파일 이름 `NNN-영문-kebab.md`, 번호는 시간 순. 결정을 뒤집으면 지우지 않고 새 번호로 쓰고, 옛 문서 상태 칸에 `폐기 (NNN)` 을 적는다.

## 형식
```markdown
# NNN. 제목 (한 문장, 무엇을 정했나)

- 날짜: YYYY-MM-DD
- 상태: 제안 | 채택 | 폐기 (NNN)

## 배경
## 결정
## 근거
(측정값, 실패 사례. 버린 대안과 버린 이유)
## 결과/영향
## 관련
```
