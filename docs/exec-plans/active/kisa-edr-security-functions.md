# KISA EDR 성능평가 보안 기능 항목 맞추기

KISA EDR 성능평가 항목 V1.4(`docs/security/kisa-edr-performance-criteria.md`)의 보안 기능 항목을 전부 통과하도록 만든다. 탐지 항목(BF-14~16, SE-01)은 `docs/security/detection-test-2026-11-10/` 에서 이미 쟀다.

## 범위

| 항목 | 내용 | 묶음 |
|---|---|---|
| BF-01 (필수) | 계정·패스워드 인증, 패스워드 조합 규칙(9자 이상, 영대·영소·숫자·특수 중 조합) | 인증 |
| BF-02 (필수) | 연속 실패 5회 이하에서 5분 이상 잠금(관리자가 설정), 관리자 즉시 통보 | 인증 |
| BF-03 (선택, 보안) | 인증 정보 재사용 방지 | 인증 |
| BF-04 (필수) | 인증 정보 화면 마스킹, 실패 사유 비공개 | 인증 + 프론트 |
| BF-05 (필수) | 보안정책 설정·조회 | 인증 |
| BF-07 (필수) | 관리용 단말 IP 제한(단일 IP 단위 등록, 범위 등록 불가) | 접근통제 |
| BF-08 (필수) | 최초 접속 시 기본 패스워드 강제 변경 | 인증 |
| BF-09 (필수) | 관리접속과 구성요소 간 암호통신 | 평가에서 확인(에이전트↔서버 TLS 1.2+ 는 있다) |
| BF-10 (필수) | 서버·에이전트 자체시험(주기 + 요청 시), 결과 조회 | 서버 자체점검, 에이전트 |
| BF-11 (필수) | 서버·에이전트 자체와 설정값 무결성 검증, 결과 조회 | 서버 자체점검, 에이전트 |
| BF-12 (필수) | 유휴 세션 종료, 중복 접속 차단 | 인증 |
| BF-13 (필수) | 서버 감사기록 생성·조회, 에이전트 감사기록 생성·서버 전송 | 감사기록, 에이전트 |
| BF-19 (선택, 보안) | 입력값 검증 | 접근통제 |
| BF-20 (선택, 보안) | 인증 없는 URL 직접 접근 통제, 권한별 접근통제 | 접근통제 |
| EF-01 (필수) | 분석 서버 재시작 시간 측정 | 평가 |

뺀 것: BF-06(관리접속이 웹 하나라 해당없음), BF-17 IPv6, BF-18 이중화(보안 기능이 아니다).

## 진행 순서

묶음마다 워크트리 하나, PR 하나. 같은 파일을 많이 건드리는 묶음은 다음 물결로 미룬다.

1. 1차(병렬)
   - **감사기록 서버**: api-service `audit` 패키지(테이블, 기록 서비스, 조회 API, 에이전트 감사기록 받는 내부 API)
   - **서버 자체점검**: api-service 자체시험과 무결성 검증, 결과 조회·요청 API
   - **에이전트**: 주기 자체시험, 바이너리·설정 무결성 검증, 감사기록 생성과 collector 경유 서버 전송
2. 2차(병렬, 1차 머지 뒤)
   - **인증**: BF-01~05, 08, 12
   - **접근통제**: BF-07, 19, 20
3. 3차: **프론트** 설정·감사기록·자체점검 화면, 로그인 화면 보완
4. 4차: **평가** 로컬 스택에서 항목별로 시험하고 화면·응답을 증거로 남긴다. EF-01 재시작 시간을 잰다.
